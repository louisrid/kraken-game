# KRAKEN — rarity trivia for 1–8 divers

Name something. The rarer your answer, the deeper you sink.
A browser-based game with a Netlify Server and Netlify Database for question history. Live at https://kraken-game.netlify.app/ (Netlify deploys every push to `main`).

Open the link and you're straight into a solo dive with the answer box ready. Everyone gets a random lowercase name and a diver; open the always-available top-left menu to change your name and profile picture. No sound.

## Multiplayer
No codes. The multiplayer screen has one shared public lobby with live player counts. Tap it to open or join. The host picks a mode, then taps **Start game**. Late joiners watch, then play the next game.

| Mode | Prompts | Timer | Win |
|---|---|---|---|
| Versus | 10 | none | deepest diver |
| Team | 10 | none | shared depth, beat your team best |
| Blitz | 5 | none | deepest diver (quick game) |

### Scoring
- Tiers: Common 100 m · Uncommon 200 m · Decent 400 m · Rare 800 m · Hyper rare 1,500 m · 1 in a Kraken 2,500 m.
- Common is only the handful of answers everyone says first. Rarer answers sink you deeper; Kraken is reserved for the genuinely obscure.
- **Versus and Blitz:** pure rarity, no adjustment for what others said.
- **Team:** depths add up, but matching a teammate sinks you both (0 m). Aliases count as the same answer (NYC = New York).
- The last prompt counts double. Solo is just the base tiers.
- No clocks. A prompt ends when everyone has answered (the host can stop waiting). Scores and answers remain hidden until every diver finishes sinking, including opponents going deeper than you. After the reveal the next prompt starts by itself; the host can tap Next prompt sooner. Drag the water to look at every rarity zone. Below you the water is drawn in equal-height rarity zones (not to scale) that fade softly into each other.

## Answers
112 prompts across 10 categories, with broad and specific topics: films, TV shows, songs, bands and singers, books, apps, video games, YouTubers, sweets, fast food, toys, animals, cities and more. `bank.js` is hand-written, `bank-gen.js` is generated by `tools/build-bank.mjs` (open datasets, including 1,000 acclaimed films, ~1,000 artists, ~1,000 hit songs and classic books), `bank-fun.js` adds broad prompts while retaining the specific ones, and `bank-extra.js` adds 40 authored prompts.
- word games (rhymes, Q-words, -ology, double Z), ranked by word frequency (SCOWL), rhymes from the CMU dictionary, profanity filtered, exact spelling only
- cities (about 30,000, ranked by population), capitals, every country, any Pokémon, comic heroes and villains, birds, music genres, fruit, veg, tech companies, car brands
- extra dog breeds, dinosaurs, programming languages and Google Fonts added to hand-written prompts

Ranked data is split about half Decent, 30% Rare, the rest Hyper rare; Kraken is hand-picked (plus the rarest ~3% of words in the word games). Unranked extras (an obscure dinosaur, a little-known font) go to Rare.

Matching is generous: capitals, accents, punctuation, plurals, aliases and typos are forgiven; one word of an answer ("grudge"), its first five letters ("strawb") or the answer inside a phrase all count. If several answers fit, the best-known one is taken. Word games still need the real word (one typo allowed).

**Profile:** best dive, average, number of dives and Krakens are kept per player. They are tied to a hashed form of your public IP (the IP itself is never stored), so devices on the same connection share them; they are mirrored on the public relays. Changing networks (mobile data, VPN) starts a separate profile.

Questions are parsed the first time they are used and pre-parsed in idle time, so the big lists don't slow down loading.

Rebuild after editing `tools/build-bank.mjs`:
```
cd tools && npm i && node build-bank.mjs
```

Run `npm run sync:questions` after changing any question source to update the server bank. Run `npm test` and `npm run check:questions` to verify the content and selection rules.

Question history is stored in Netlify Database using an anonymous browser cookie, separately from profile statistics. The selector excludes questions reserved or shown to anyone in the match within the last hour, including across refreshes and host changes. Reservations are atomic for overlapping games, and each displayed prompt refreshes its cooldown. If there are too few fresh questions, the game asks players to wait rather than repeating them. Database migrations are applied automatically during deployment.

## How multiplayer works
- The host's browser runs the game; everyone else sends intents and renders the host's state.
- Messages go over 5 public MQTT relays at once; guests keep whichever answers first. The port-443 relay gets through strict networks.
- Refresh = rejoin your seat. If the host leaves, everyone is sent home within a couple of seconds.

## Files
index.html (layout + styles), game.js (host/guest logic + UI), engine.js (answer matching + scoring), bank.js + bank-gen.js (prompts), art.js (kraken, avatars, icons), net.js (relays), mqtt.min.js, tools/ (bank generator).

## Local testing
Install dependencies with `npm install`, then run `netlify dev --port 8889` for the static frontend and API routes. Database-backed gameplay requires the deployed migration; do not apply production migrations manually. Browser layout and animation checks can stub the question API independently.

For a local MQTT-over-WebSocket broker (e.g. aedes on :8890), open `http://localhost:8889/index.html?relay=ws://localhost:8890`. The `?relay=` override only works on localhost.
